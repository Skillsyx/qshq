# 青山花卉微信小程序

## 项目概述
青山花卉微信小程序是一个花卉销售平台，提供线上购物和预订服务。用户可以浏览花卉商品，添加到购物车，并通过快递配送或到店自取的方式完成购买。

## 功能列表

### 已完成功能
- 用户认证（微信登录）
- 商品列表展示
- 购物车功能（添加商品、本地存储）

### 待开发功能
- 结账流程
  - 快递模式（收货地址管理、运费计算）
  - 预订模式（预订时间选择、预订信息确认）
- 订单管理
  - 订单创建和状态管理
  - 订单列表展示
  - 订单详情页面
- 支付集成
  - 微信支付接入
  - 支付状态同步

## 技术栈
- 前端：微信小程序原生开发
- 后端API：RESTful API
- 数据存储：本地存储 + 云端数据库

## 项目结构
```
├── pages/                  # 页面文件夹
│   ├── goods/              # 商品列表页
│   ├── cart.js             # 购物车页面
│   ├── checkout/           # 结账页面
│   │   ├── express/        # 快递模式结账
│   │   └── reserve/        # 预订模式结账
│   └── order/              # 订单管理页面
├── utils/                  # 工具函数
│   └── productApi.js       # 商品API接口
└── app.js                  # 小程序入口文件
```

## 安装和运行
1. 克隆项目到本地
2. 使用微信开发者工具打开项目
3. 在微信开发者工具中点击"编译"按钮运行项目
